命令为 python run_bcs.py；g=0.30，假设 E_c=20 meV。环境为 Python 3.12.4、NumPy 1.26.4、SciPy 1.13.1、Matplotlib 3.8.4。

| 指标 | 结果 | 解释 |
|---|---|---|
| Δ₀/E_c | 0.07143890225625 | 精确公式 1/sinh(1/g) |
| k_BTc/E_c | 0.04044952519089 | 独立线性化求根 |
| 2Δ₀/(k_BTc) | 3.532249237493 | 有限截断结果 |
| 弱耦合极限 | 3.527753977724 | g→0 的解析基准 |
| 假设截断下 Tc | 9.387944961716 K | 未对应具体材料 |
| 非零解最大残差 | <3.88×10⁻¹³ | 默认温度扫描 |
| 容差 10⁻⁶ 到 10⁻¹⁰ 的 Tc 相对变化 | <2.23×10⁻¹⁶ | 本参数下积分稳定 |

执行 python -m unittest -v test_bcs.py，**7 项全部通过**。交互 Notebook 的 7 个代码单元也已从头执行，无错误输出。
测试覆盖零温积分、弱耦合极限、能隙非增趋势、线性化端点、耦合趋势、DOS 及单位/输入。低温指数小变化可能低于浮点精度，单调性允许数值容差。
