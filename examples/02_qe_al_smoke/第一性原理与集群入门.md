# 第一性原理材料计算与集群入门

Density Functional Theory → Density Functional Perturbation Theory → Electron–Phonon Coupling → Eliashberg

本课用一个真实、低成本、可审计的铝（Aluminum）测试，连接 BCS 的模型参数和材料计算。
第一次阅读预计 2–3 小时；真正的声子/EPC 收敛和材料 Tc 预测需要后续独立项目。
配套脚本见 [本课入口](README.md)，实际证据见 [测试记录](集群测试记录.md)。

## 1. 先理解每一步的作用

| 阶段 | 输入 | 主要输出 | 能否直接说明超导 |
|---|---|---|---|
| DFT / Kohn–Sham | 原子结构、泛函、赝势 | 常态电荷密度、能带、力、应力 | 不能仅靠金属能带判定 |
| SCF | 密度初猜与数值参数 | 自洽密度和总能量 | 只是后续基础 |
| DFPT / ph.x | SCF 基态、q 点与响应阈值 | 动力学矩阵、声子与势响应 | 声子存在不等于 EPC 足够强 |
| EPC | 电子态、声子、微扰势矩阵元 | g_mnν(k,q)、α²F(ω)、λ | 还需要配对方程和 Coulomb 处理 |
| Eliashberg | α²F 或各向异性配对核、μ* 等 | 能隙、重整化函数、Tc | 在模型与近似范围内预测 |
| 与实验/论文比较 | 收敛结果、材料条件 | 误差、差异来源、图表对比 | 不能把吻合一个数当作机制证明 |

常态 DFT 的 Kohn–Sham 本征值不是 BCS 准粒子能量。SCF 的电子 smearing 不是超导温度扫描。
本例的 Al 结构与 BCS 例子的 g=0.30、E_c=20 meV **没有参数映射**，不能混在一起给出铝的 Tc。

## 2. 为什么选 Al

fcc 金属、单原子原胞、已有 PBE PAW 赝势，适合检查程序和输入。
这里用的是固定晶格，不先做结构优化，以避免把多个问题同时引入。
常规晶格长度 a=7.65339 Bohr≈4.05 Å；fcc 原胞有一个原子，而不是四个。

单原子原胞总共 3 个声子分支，全部是声学分支。理想 Γ 点对应整体平移，频率应为零。
因此 Γ 点测试特别适合教学数值残差，但无法显示有限 q 的声学色散，也不能证明全布里渊区动力学稳定。

## 3. 理解 scf.in

文件原文就在本目录，无需从图片抄参数。

### CONTROL：这次要算什么

- calculation='scf'：固定结构的电子自洽场。
- prefix='al'：数据命名前缀。ph.x 必须与它一致。
- outdir='./scratch'：保存电荷密度与波函数；后续声子依赖这些数据。
- pseudo_dir：赝势实际目录。本例为 /home/runhan/apps/qesssp。
- tstress、tprnfor：输出应力和力用于诊断，不代表已经优化晶格。

### SYSTEM：物理模型与基组

| 参数 | 本例 | 解释 |
|---|---|---|
| ibrav | 2 | QE 约定的 fcc 原胞 |
| celldm(1) | 7.65339 | 晶格常数，单位 Bohr |
| nat / ntyp | 1 / 1 | 原子数 / 元素类型数 |
| ecutwfc | 40 Ry | 波函数平面波动能截止 |
| ecutrho | 320 Ry | 电荷密度截止；PAW 增广密度要独立留意 |
| occupations | smearing | 金属积分占据处理 |
| smearing | mv | Marzari–Vanderbilt / cold smearing |
| degauss | 0.02 Ry | 数值展宽，约 0.272 eV，不是配对截止 E_c |

Ry（Rydberg）≈13.6057 eV，Bohr≈0.529177 Å。
DFT cutoff 指基组规模；BCS cutoff 指配对作用的能量窗口，两者完全不同。

### ELECTRONS：自洽迭代

conv_thr=1.0d-10 是 QE 的总能量相关 SCF 收敛阈值（Ry）。
mixing_beta=0.5 控制新旧电荷密度混合。收敛困难时需检查结构、占据、空带和混合，而不是只把阈值调松。
最终要看 convergence has been achieved 与实际 accuracy，不只看结束标记。

### 原子与 k 网格

ATOMIC_POSITIONS crystal：分数坐标，Al 在原点。
K_POINTS automatic 的 8 8 8 1 1 1 表示每方向 8 点并启用半步偏移。
对称性约化后输出 60 个不可约 k 点；它们的积分权重由程序处理。
这是冒烟测试网格，不是 EPC 收敛网格。

## 4. 赝势不是可以随意替换的黑盒

本例使用 Al.pbe-n-kjpaw_psl.1.0.0.UPF：

- PBE exchange–correlation functional（交换关联泛函）。
- PAW（Projector Augmented-Wave）类型，3 个价电子。
- Scalar relativistic（标量相对论）设置。
- 集群已有文件，头信息给出生成者 A. Dal Corso；文件级 SHA256 见测试记录。

必须让 SCF、声子与后续 EPC 使用一致赝势。比较论文时还需匹配泛函、SOC、价电子、晶格和赝势版本。
头信息建议的 cutoff 只是起点，不等于你的目标量已收敛。
本仓库没有再分发该 UPF；自行获取时应确认来源与许可并验证校验值。

## 5. SCF 实际输出怎么看

阅读 results/output，优先找：

~~~text
Program PWSCF v.7.5
number of electrons = 3.00
the Fermi energy is 7.8174 ev
! total energy = -39.50303902 Ry
estimated scf accuracy < 1.5E-11 Ry
convergence has been achieved in 5 iterations
JOB DONE.
~~~

这些是本次输入的实际结果，不是实验数据。
有限 smearing 下该输出把总能量标为 F=E−TS；比较不同 degauss 时必须注意约定，
不能混用 total energy 与 internal energy。
赝势总能量的绝对值也不能跨不同赝势直接比较。

金属本征值穿越费米能说明常态金属性；它不包含这里尚未求解的超导异常密度和配对序参量。
应力未必为零，因为 a 固定。若开始材料预测，要先决定使用实验结构还是优化结构并写明条件。

## 6. Γ 点 DFPT 输入

ph.in 设置：

- prefix 与 outdir 和 SCF 一致。
- tr2_ph=1.0d-12：线性响应迭代的收敛控制。
- ldisp=.false.：只计算给定单 q 点。
- fildyn='al.gamma.dyn'：保存动力学矩阵。
- namelist 后一行 0.0 0.0 0.0：Γ 点。

不能在声子计算开始前删除 scratch/al.save，也不能把另一次 SCF 的 scratch 混进来。
升级软件或改变并行布局前应确认 checkpoint 格式兼容；初学阶段优先在新目录完整重跑。

## 7. 如何解释负频率与声学和规则

原始 ph.x 的三个 Γ 频率均为 −3.374924 cm⁻¹。
QE 的带负号频率表示对应负的动力学矩阵本征值，即虚频表示，不是“负能量声子”。

对当前单原子 fcc 原胞，Γ 平移声学模理论上为零。离散 k 网格、响应误差和未施加平移约束会留下残差。
**不能仅凭这个结果宣布 Al 不稳定，也不能直接把所有负频率删除。**

ASR（Acoustic Sum Rule）表达整体平移不产生回复力。dynmat.in 使用 asr='crystal' 对 Γ 动力学矩阵
施加三个平移约束，写出独立 al.gamma.asr.modes，不覆盖 al.gamma.dyn。

正确的教学记录包括：原始值、ASR 方案、处理后值和版本。
即使后处理得到零，也不等于电子 k 网格、q 网格或有限 q 的声子已收敛。
若有限 q 有明显虚频，必须做更密网格、参数和结构检查，并考虑真实不稳定，不能用 Γ 的解释包办。

## 8. 本次集群资源与提交

按照 HostBridge 的计算约定，科学计算放 Slurm 计算节点，不在登录节点直接启动 pw.x/ph.x。
环境：

~~~bash
module load StdEnv/2023 gcc/12.3 openmpi/4.1.5 quantumespresso/7.5
~~~

主脚本申请 iq-main、账户 def-maiagv、4 MPI、每进程 1 线程、8 GB、20 分钟。
作业名为 test，pw.x 标准输出为 output，ph.x 输出为 phonon.output。
这些是当前集群测试设置，不是所有服务器通用的默认值。

~~~bash
sbatch submit.sh
# 记录返回的 JobID，不要因为工具响应超时就重复提交。
sacct -j JOBID --format=JobID,State,Elapsed,ExitCode
tail -n 40 output
tail -n 40 phonon.output
~~~

如果已完成任务从 squeue/scontrol 消失，用 sacct 与确定路径的输出联合检查，
不能把 Invalid job id 自动解释成失败。
本次 313274 就是在 sacct 中确认 COMPLETED，同时核对了计算结束标记。

HostBridge 的 Direct MCP 模式使用结构化写文件、slurm_submit 和 slurm_snapshot。
每次修改操作有稳定 command_id，重试沿用同一 ID，避免重复写入或提交。
提交成功后 Slurm 接管任务；返回 JobID 是持久检查点，不代表科学任务完成。
只在下一步决策需要新证据时查看状态，避免无意义轮询。

## 9. 从跑通到可靠：建议下一组收敛练习

以下是计划，不是本次已经计算的结果。一次只改变一个因素，在独立目录保存输入和输出。

| 练习 | 起始扫描 | 比较量 | 完成标准 |
|---|---|---|---|
| 波函数 cutoff | 40、50、60 Ry | 每原子能量差、应力、指定 q 频率 | 事先写误差目标 |
| 电荷 cutoff | 固定 ecutwfc，独立扫描倍数 | 同上 | PAW 增广密度不能忽略 |
| 电子 k 网格 | 8³、12³、16³ | 能量、EF、频率 | 与 smearing 联合检查 |
| 金属 smearing | 0.02、0.01、0.005 Ry | 能量约定、频率、积分噪声 | 网格足够密才缩小展宽 |
| 非 Γ 声子 | 从单个高对称有限 q 开始 | 频率、响应收敛 | 排除真实/数值虚频 |
| 全 q 网格 | 从小网格开始 | 色散、声子 DOS | 不只看 Γ |

能量例如可先要求最后两档变化 <1 meV/atom，频率例如 <1 cm⁻¹，
但这些是**练习用初始目标**，不自动满足超导 Tc 的误差需求。
最终应以目标可观测量（λ、α²F、Tc 等）的稳定性决定采样。
在零附近应比较绝对频率/动力学矩阵误差，不用除以接近零的频率计算百分误差。

## 10. 真正声子介导超导还缺什么

电子–声子矩阵元是电子态对位移诱导势的响应。EPC 耦合 λ 常写为

$$
\lambda=2\int_0^\infty\frac{\alpha^2F(\omega)}{\omega}d\omega.
$$

这里使用与 α²F 定义一致的频率/能量单位。低频权重会放大数值误差，因此只有 Γ 结果远远不够。

完整步骤通常包含：

1. 固定模型与结构条件，验证 DFT 和 DFPT 收敛。
2. 构建电子/声子粗网格与 EPC 数据。
3. 如使用 EPW，建立 Wannier 表象并验证插值能带和声子。
4. 对费米面电子 k、声子 q、双 δ 展宽等做收敛。
5. 计算 α²F、λ 与相应频率矩，再求各向同性/各向异性 Eliashberg。
6. 报告 μ* 或屏蔽处理的来源和敏感性，不把它当任意拟合旋钮。
7. 选择原论文的一张图或一张表，统一条件后比较并写误差分析。

本次只验证 pw.x/ph.x 的运行；模块中已定位 epw.x，但**没有执行 EPW 超导计算**。
推荐后续以 [EPW 官方 Pb/MgB2 教程](https://docs.epw-code.org/tutorials/tutorial_04/index.html) 为独立复现任务，
先确认对应软件版本、赝势、输入和计算成本。本文未复制它的整套数据。

## 11. 常见错误排查

| 情况 | 先检查 |
|---|---|
| module 后仍找不到程序 | module list 和 command -v；不要盲目混 MPI 编译器 |
| pw.x 无法读 UPF | pseudo_dir、文件名、读权限和校验值 |
| SCF 振荡 | 结构、金属占据、k 网格、mixing_beta、空带 |
| ph.x 找不到基态 | prefix/outdir、完整 al.save、SCF 是否真正完成 |
| 作业 COMPLETED 但结果不完整 | ExitCode、应用日志、脚本是否漏掉错误检查 |
| Γ 有小虚频 | 保留原始值，查 ASR 和参数收敛，不直接宣布不稳定 |
| Tc 不稳定 | 费米面/EPC 采样、展宽、μ*、插值质量和声子误差 |

## 12. 本课练习

1. 解释为什么 fcc 原胞 nat=1，Γ 只有 3 个模而没有光学模。
2. 从 output 提取软件版本、EF、总能量、accuracy 和迭代数。
3. 不运行任何新任务，用 check_results.py 重建日志摘要。
4. 对比原始与 ASR 结果，写出为什么这不是声子收敛证明。
5. 设计 ecutwfc 收敛表，列出固定参数、目标误差和每档独立目录。
6. 将本文参数与一篇论文的计算细节比较，不同项逐一列出。

答案要点：一个原子有三个自由度；整体平移在 Γ 为三个声学模；
ASR 加入物理约束但并未改进原始电子采样；需要目标量收敛才能转入定量超导分析。
