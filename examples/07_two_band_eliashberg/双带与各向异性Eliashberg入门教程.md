# 双带与各向异性 Eliashberg 入门教程

Two-Band and Anisotropic Migdal-Eliashberg Theory

[案例入口](README.md) · [已执行 Notebook](双带Eliashberg交互教程.ipynb) · [上课内容](../06_epc_eliashberg/电子声子耦合与Eliashberg入门教程.md)

## 0. 本课回答什么

上一课把整个费米面的配对信息压缩成一条 α²F(Ω)。
本课问：如果不同电子带受到的散射不同，怎样让代码保留这种差别？
我们从两个离散带组出发，不先启动昂贵材料计算。

完成后应能自己解释：为什么 λ_AB 不必等于 λ_BA；DOS 权重应乘几次；
为什么多条能隙可以在同一个临界点出现；怎样检验矩阵展开没有弄错索引。

“多带”（multiband）描述电子自由度，“各向异性”（anisotropy）描述空间/动量依赖，
“声子介导”（phonon-mediated）描述配对作用来源。它们不是互斥分类。
双带模型既可能用于声子体系，也可能用于别的有效作用；本课只实现正的声子 Einstein 核。
不要把本课当作自旋涨落、排斥 Hubbard 或符号反转 s± 机制的通用求解器。

## 1. 先把五个层次分开

| 层次 | 未知量 | 丢失的信息 |
|---|---|---|
| BCS 常数模型 | 一个 Δ(T) | 频率结构与费米面差别 |
| 各向同性 Eliashberg（isotropic） | Δ(iwₙ)、Z(iwₙ) | 带与带内 k 差别 |
| 双带平均（band-averaged） | Δ_A(iwₙ)、Δ_B(iwₙ) | 每条带内的 k 差别 |
| 费米面 patch 模型 | 每个区域的 Δ、Z | patch 内的细节 |
| 完整带/k 分辨（fully anisotropic） | Δ_bk(iwₙ)、Z_bk(iwₙ) | 仍依赖选用的多体近似 |

本代码属于第三层。函数支持少量离散组，但本课只固定两个带组。
“带”在这里是粗粒化分组，不是显式计算了两个真实 Bloch 能带。
真实材料还需要电子色散、费米面测度、声子及矩阵元；两个 λ 数字不能补齐这些信息。

## 2. 符号、单位与数据形状

| 符号 / 代码 | 含义 | 单位 / 形状 |
|---|---|---|
| i,j | 起始带与目标带 | A 或 B |
| n,m | 正虚频编号，从 0 起 | 整数 |
| pᵢ / `weights` | 同一自旋约定下的部分 DOS 占比 | 正数，和为 1 |
| Vᵢⱼ / `bare_lambda` | 未吸收目标带权重的有效谱幅度 | 对称、无量纲，2×2 |
| λᵢⱼ / `lambda_matrix` | 已吸收 pⱼ 的散射核静态幅度 | 无量纲，2×2 |
| Uᵢⱼ / `bare_mu` | 未吸收目标带权重的有效库仑赝势 | 对称、无量纲，2×2 |
| μ*ᵢⱼ / `mu_matrix` | 已吸收 pⱼ 的库仑赝势 | 无量纲，2×2 |
| Ω_E / `omega_meV` | 共同 Einstein 声子能量 | meV |
| wₙ | 费米 Matsubara **能量** | meV |
| Δᵢₙ / `gap_meV` | 虚轴能隙函数 | 2×N，meV |
| Zᵢₙ | 质量重整化函数 | 2×N，无量纲 |

这里用能量而不是角频率，wₙ=(2n+1)πk_B T，k_B=0.08617333262145 meV/K。
μ* 是库仑赝势（Coulomb pseudopotential），不是化学势 μ。
V 是教学有效矩阵，不是一个以 eV 为单位的裸 Coulomb 势；称为 `bare` 仅指尚未吸收 pⱼ。
程序不从 DFT 的 N(E_F) 自动生成 μ*，也没有重新推导多带 Morel-Anderson 重整化。

## 3. DOS 权重从哪里来

若两条带在费米能附近的部分态密度是 N_A、N_B，且采用相同自旋与体积约定，定义

$$p_A=\frac{N_A}{N_A+N_B},\qquad p_B=\frac{N_B}{N_A+N_B}.$$

它不是“能带有两条所以各占 1/2”，也不是“每条带用了相同 k 点所以各占 1/2”。
真实费米面权重含积分测度，不能只按散点个数计数。
本模型人为固定 p=(0.4,0.6)，不声称来自 MgB₂。

把费米面求和按组分块，在每组内近似 Δ、Z 与核为常数，则

$$\sum_{k'\in j} W_{k'}\,V_{ij}f_j\ \longrightarrow\ p_j V_{ij} f_j.$$

为了让代码的带求和更简单，规定

$$\lambda_{ij}=V_{ij}p_j,\qquad \mu^*_{ij}=U_{ij}p_j.$$

之后使用 `sum_j lambda_ij * ...`，**不要再乘 pⱼ**。
另一种教材也可把 pⱼ 放在求和外，但那时它的 λ 定义与本课不同。比较论文矩阵前先查约定。

### 3.1 为什么 λ_AB ≠ λ_BA 仍合理

假设 Vᵢⱼ=Vⱼᵢ，则

$$p_i\lambda_{ij}=p_ip_jV_{ij}=p_j\lambda_{ji}.$$

这是本模型的加权互易关系（weighted reciprocity），不是对 λ 本身做普通对称化。
本课固定

$$V=\begin{pmatrix}2.5&0.3\\0.3&1.0\end{pmatrix},\quad
\lambda=\begin{pmatrix}1.0&0.18\\0.12&0.60\end{pmatrix}.$$

手算：0.3×0.6=0.18，0.3×0.4=0.12；0.4×0.18=0.6×0.12=0.072。
如果输入矩阵被强制平均成对称矩阵，已经改变了有效散射权重。
如果把“已加权 λ”误传入 `bare_lambda`，程序会再次乘 pⱼ，这是使用约定错误，不能靠曲线漂亮判断。

### 3.2 行和与全局平均

带分辨质量耦合行和为 λ_A=1.18、λ_B=0.72。
整个费米面平均为

$$\bar\lambda=\sum_i p_i\sum_j\lambda_{ij}=0.4(1.18)+0.6(0.72)=0.904.$$

不是矩阵四个元素的算术平均，也不是只平均两个对角元。
本课 U 的全部元素取 0.1，得到 μ* 的两行均为 (0.04,0.06)，每行和为 0.1。
我们选择的是常数未加权赝势，而不是“每一个已加权 μ*ᵢⱼ 都等于 0.1”。

## 4. 保留迟滞的 Einstein 核

为每个带对定义单模式能量轴谱

$$A_{ij}(\Omega)=\frac{\lambda_{ij}\Omega_E}{2}\delta(\Omega-\Omega_E).$$

由此得到

$$K_{ij}(\nu)=\frac{\lambda_{ij}\Omega_E^2}{\Omega_E^2+\nu^2}.$$

静态值 Kᵢⱼ(0)=λᵢⱼ；核对 ν 是偶函数，随频率差衰减。
共同 Ω_E=10 meV 只是最小示范，真实材料的四条 Aᵢⱼ(Ω) 不必有相同谱形。
本课没有使用常数 K=λ 代替迟滞核，也没有由声子 DOS 猜测耦合。

## 5. 全正负频率方程

在恒定 DOS、费米面限制、偶频实序参量的教学近似下，记

$$E_{jm}=\sqrt{w_m^2+\Delta_{jm}^2}.$$

频率编号此时遍历负与正整数。本课使用的模型方程为

$$Z_{in}=1+\frac{\pi k_BT}{w_n}\sum_{j,m}
K_{ij}(w_n-w_m)\frac{w_m}{E_{jm}},$$

$$Z_{in}\Delta_{in}=\pi k_BT\sum_{j,m}
\left[K_{ij}(w_n-w_m)-\mu^*_{ij}\Theta(\Omega_c-|w_m|)\right]
\frac{\Delta_{jm}}{E_{jm}}.$$

注意目标频率 m 的库仑截止；本模型在整个有限外部频率 n 范围计算 Δ。
μ* 与其选用的截止是同一有效模型的输入约定，不应改变截止又默认为 μ* 完全不变。
这里 Ω_c=100 meV，有限 Matsubara 求和与库仑截止是两个不同概念。

恒定 DOS（constant DOS）不等于各向同性（isotropic）。
即使沿电子能量 ξ 的变化忽略，A、B 两个带的相互作用仍可不同。
这里不解能量位移 χ 或粒子数约束，因此不是全带宽（full-bandwidth）理论。

## 6. 正虚频折叠，一步一步来

实际存储 n,m=0,…,N−1。负频率与正频率成对：w_{−m−1}=−w_m。
偶频假设给 Δ_j(−iw_m)=Δ_j(iw_m)，Z 同样是偶函数。
定义

$$K^-_{ij,nm}=K_{ij}(w_n-w_m),\qquad K^+_{ij,nm}=K_{ij}(w_n+w_m).$$

正常项分子 w_m 是奇函数，所以正负配对后是 K⁻−K⁺；
配对项 Δ 是偶函数，所以是 K⁻+K⁺。库仑对两侧都贡献，故是 **2μ***。

$$Z_{in}=1+\frac{\pi k_BT}{w_n}\sum_{j,m\ge0}
(K^-_{ij,nm}-K^+_{ij,nm})\frac{w_m}{E_{jm}},$$

$$\Delta_{in}=\frac{\pi k_BT}{Z_{in}}\sum_{j,m\ge0}
\left[K^-_{ij,nm}+K^+_{ij,nm}-2\mu^*_{ij}\Theta(\Omega_c-w_m)\right]
\frac{\Delta_{jm}}{E_{jm}}.$$

只增加两个带标签，没有改变折叠的奇偶逻辑。
测试不是复制本公式后与自身比较，而是重新建立 2N 个有符号频率逐项求和。

## 7. 临界点：2N×2N 本征问题

临界附近把 Δ 线性化，Eⱼₘ≈w_m，先求正常态

$$Z^{(0)}_{in}=1+\frac{\pi k_BT}{w_n}\sum_{j,m}(K^-_{ij,nm}-K^+_{ij,nm}).$$

构造

$$B_{(i,n),(j,m)}=\frac{\pi k_BT}{Z^{(0)}_{in}w_m}
\left[K^-_{ij,nm}+K^+_{ij,nm}-2\mu^*_{ij}\Theta(\Omega_c-w_m)\right].$$

方程是 Δ=BΔ；跟踪最大**实**配对本征值达到 1，而不是绝对值最大的本征值。
例如本征值 (−5,0.9,0.3) 的最大绝对值是 5，但当前实吸引不稳定性仍是 0.9，尚未达到 1。
μ* 截止仅作用于目标频率，B 通常不对称，应使用一般本征求解器，不强行用 `eigh`。

### 7.1 索引是最容易错的地方

四维核形状 `(i,j,n,m)`，目标矩阵形状 `(i,n,j,m)`，因此：

```python
matrix = blocks.transpose(0, 2, 1, 3).reshape(2*N, 2*N)
```

展开顺序为 `(A,0)…(A,N−1),(B,0)…(B,N−1)`。
如果直接 reshape，没有先交换 j,n，矩阵可能仍有本征值，却对应错误物理。
带标签置换测试和单带嵌入测试共同检查此处。

### 7.2 二分找 Tc

输入温度区间 2–25 K，低温端要求 ρ>1，高温端要求 ρ≤1。
每次取中点，保留两端性质，直到区间宽度≤0.01 K。
返回区间而不是虚假的十位有效数字。

固定模型得到 [10.09155,10.09717] K。
二分宽度不是材料误差棒，也不是 Matsubara 截止误差。
阶跃库仑截止的格点包含数会随温度变化，有限模型不严格处处光滑；
此算法只定位给定区间的阈值，不能为任意多带参数证明唯一 Tc 或全部竞争分支。
本课不通过调 μ* 把结果拟合到实验。

## 8. 非线性求解与“真正的残差”

低温对每个连通分组使用其主本征模式作为非零初值；正常分组用零能隙。
两个完全解耦的带可能各自不稳定，不能只初始化全局最强的一条，否则另一条会被困在零解。
分组只计当前温度实际保留的作用；若最低虚频已高于库仑截止，被截止的库仑矩阵不能用于连接带。
非零初值重要，因为 Δ=0 在所有温度都是方程的平凡解。
带内没有显式复相位，主模整体符号只是规范选择，不代表相位敏感测量。

每步用旧 Δ 计算 E，得到未混合的 Z_new、Δ_new，然后检查

$$r_\Delta=\max_{i,n}|\Delta^{new}_{in}-\Delta_{in}|<10^{-8}\ \mathrm{meV},$$

$$r_Z=\max_{i,n}|Z^{new}_{in}-Z_{in}|<10^{-9}.$$

未通过时使用混合（mixing）：x←0.7x+0.3x_new。
不能只用混合后的步长，混合因子很小可能把错误残差隐藏成“小变化”。
未达到阈值或坍缩到零解就报错，不把最后一次迭代默认称为收敛。

4 K 两个最低虚频值约为 1.86538、0.87471 meV。
在 10 K，ρ≈1.004，临界慢化（critical slowing down）使混合迭代需约 4923 步。
温度演示显式给 10000 步预算；普通 `solve_gap` 默认 4000 步，故同温度默认调用可能失败。
失败后应解释原因、记录迭代预算，不悄悄提高残差阈值。

这不是 Broyden 算法，也没有自由能排序或全局唯一解证明。
本课只研究给定正声子矩阵、弱带间排斥下的主偶频分支。

## 9. 单带极限：建立一个不依赖曲线观感的验收

若 Vᵢⱼ=λ₀ 对所有带对相同，Uᵢⱼ=μ₀*，则
λᵢⱼ=λ₀pⱼ，μ*ᵢⱼ=μ₀*pⱼ。
两行的 λ 和都等于 λ₀，μ* 和都等于 μ₀*。
把两个带的 Δ、Z 设成同一函数，求和 Σⱼpⱼ=1 后精确退化到单带方程。

这是**相同相互作用的精确极限**。本课真实示范矩阵不在该极限。
验证时把任意频率向量 v 同时嵌入两带，比较

$$B_{2band}(v,v)\stackrel{?}{=}(B_{1band}v,B_{1band}v).$$

最大误差约 1.67×10^-16，同时 Z 也一致。
再检查非线性解退化、带标签交换与解耦块，不能只验证一个 Tc 数字。

## 10. 同平均 λ 对照，为什么值得做

创建一个各向同性有限模型：λ=0.904、μ*=0.1，其他能标和虚频数不变。
得到 Tc 区间 [7.87915,7.88477] K，与双带约 10.09 K 不同。

这是“先平均核再求解”的对照，不是对已经求出的双带 Δ 做平均。
双带矩阵主模会选择更有利的带组合，Z 也按带变化，所以不能认为只知道平均 λ 就知道全部配对结果。
但本例不能证明所有各向异性模型 Tc 更高，更不能推出任意材料的增强比例。
若谱形不同、Coulomb 矩阵不同、杂质混带或近似失效，比较会发生变化。

图中 Δ(iw₀) 与真实实轴激发能隙（excitation gap）不是同一个量。
没有解析延拓（analytic continuation），就不要据此生成隧穿 DOS 或声称复现实验能隙。

## 11. 如何阅读代码

1. `Model` 检查权重、对称未加权矩阵、正能量与矩阵尺寸；生成已加权 λ、μ*。
2. `kernels` 生成正频率、正常差核与配对和核。
3. `linearized` 求正常 Z，交换索引并生成 B。
4. `leading_eigenpair` 选最大实本征对，规范化主模并检查残差。
5. `find_tc` 检查两端并二分。
6. `solve_gap` 按连通分组分别选分支、非线性更新、检查未混合残差。
7. `run_learning.py` 固定参数出图和报告，不接触集群。
8. `test_two_band.py` 建立独立全有符号频率参考，不调用生产折叠核。

示范接口：

```python
import numpy as np
from two_band import Model, find_tc, solve_gap
model = Model([.4, .6], [[2.5, .3], [.3, 1]], np.full((2, 2), .1))
print(model.lambda_matrix)
print(find_tc(2, 25, model))

print(np.array(solution['gap_meV'])[:, 0])
```

## 13. 练习与参考答案

### 练习 1：发现一次重复权重

有人写 `sum_j p[j]*lambda_matrix[i,j]*f[j]`，哪里错？

答案：本课 λ 已含 pⱼ。正确是只乘 λ；若保留 pⱼ，必须改用未加权 V。
检查静态行和是否仍是 1.18 和 0.72，可快速暴露错误。

### 练习 2：数值检验互易

计算 p_Aλ_AB 与 p_Bλ_BA，并说明为什么不用 λ_AB=λ_BA 验收。

答案：两侧均 0.072。目标 DOS 不同使已加权矩阵非对称；强制普通对称改变模型。

### 练习 3：Tc 不能由四元素平均得到

计算平均 λ，并解释它对应什么对象。

答案：0.904。先按目标带权重形成每行和，再按起始带 DOS 平均。
它是整体耦合的加权统计量，不包含完整主配对本征向量。

### 练习 4：折叠中的两个符号

正常项为什么相减？库仑项为什么乘 2？

答案：正常分子 w_m 在负频率改变符号；偶频 Δ 不改变符号。
对称库仑截止在正负两侧都出现，配对项相加得到两次排斥。

### 练习 5：识别错误的收敛判据

若混合因子取 10^-4，混合步长 10^-8 meV，能否直接宣布原方程收敛？

答案：不能，未混合残差可达 10^-4 meV。应检验未混合更新与旧值差。
混合变小只是移动变慢，不自动提高物理解的准确性。

### 练习 6：阅读 Fig. 6(a)

能否把本课两条线改名 σ、π，称为原图复现？

答案：不能。缺少材料带/k 分辨谱核、原参数和原始点集。
