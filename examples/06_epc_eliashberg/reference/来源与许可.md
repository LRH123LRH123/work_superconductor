新的中文解释、教学代码、Notebook 与 PPTX 为原创，原始参考文件保持上游身份。

- 仓库：[QEF/q-e](https://github.com/QEF/q-e)，标签 `qe-7.5`。
- 固定提交：[770a0b2d12928a67048e2f3da8d10d057e52179e](https://github.com/QEF/q-e/tree/770a0b2d12928a67048e2f3da8d10d057e52179e)。

`qe-7.5/` 下保存 Al α²F 数字表、原参考输出、Pb SCF/NSCF/EPW 输入和软件回归输出。
按上游 GPL 条款再分发，不把这些文件标作本仓库原创或重新套用其他许可证。

GPL 文件和本课独立教学材料在目录中分开，不声称上游作者认可本课。

## 2. 没有全部放进 Git 的文件

来源清单也记录 Pb 赝势及上游 `save/` 的 DFPT 动力学矩阵和势导数文件。
这些文件的 `stored_in_repository` 为 false，避免把二进制计算数据混入教学 Git 历史。
[准备脚本](../cluster/pb_regression/prepare_cluster.py) 按同一提交下载并逐一验证哈希，
不是访问可变的 `master` 文件。真实运行保留于集群每个作业的独立目录。

Pb 赝势 SHA256：`24fe8cc951a89521da24dc6bd936b462078927a6970132848a355857a82d27af`。
本课不将其宣传为针对真实 Pb 精度验证过的现代最佳赝势，它是固定回归算例的一部分。

## 3. 三种日期和版本不要混淆

标签 qe-7.5 是**参考文件所在提交**；文件内的历史程序版本和运行日期可能更早。
当前集群运行使用 QE 7.5，EPW 实际 banner 为 6.0。
在线 EPW 文档可能描述更高版本，因此不能把在线新增输入选项自动视为本地可用。
本次没有下载大型 2026 Pb/MgB2 教程的数据包，也没有运行它的全部设置。
