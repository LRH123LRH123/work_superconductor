# 计算方法与工作流

[返回首页](../../README.md) · [学习路线](../超导计算学习路线.md)

## 1. 先按问题选方法

| 想回答的问题 | 起点 | 主要输出 | 解释边界 |
|---|---|---|---|
| 给定吸引作用能否配对 | BCS 平均场 | Δ(T)、平均场 Tc | 有效吸引通常是输入，不能凭结果证明其微观来源 |
| 杂质、边界、界面能谱 | BdG | 局域态密度、序参量、束缚态 | 常依赖预设配对通道；需自洽与有限尺寸检查 |
| 涡旋与宏观磁响应 | GL/TDGL/London | 磁场、涡旋、序参量动力学 | 标准 GL 适于近 Tc，动力学系数需有依据 |
| 声子能否解释材料超导 | DFT+DFPT+EPC、Eliashberg | 声子、α²F、λ_ep、能隙与 Tc | 检查绝热近似、结构稳定性、非谐性及 Coulomb 项 |
| 排斥相互作用偏好哪种配对 | Hubbard + RPA/FLEX/fRG | 响应函数、领先与次领先配对通道 | 对相互作用、轨道与顶角截断敏感 |
| Mott 邻近或强关联配对 | QMC/DMRG/簇 DMFT 等 | 关联函数、配对顶角、有限尺寸趋势 | 受符号问题、簇/几何大小与求解器近似限制 |

## 2. 声子路线

```text
结构与压力 → DFT 收敛 → DFPT 声子 → Wannier/EPC 插值
          → α²F 与 λ_ep → Eliashberg/近似 Tc → 实验与收敛对比
```

在常见约定下：

$$
\lambda_{\mathrm{ep}}=2\int_0^\infty \frac{\alpha^2F(\omega)}{\omega}\,d\omega.
$$

必须分别检查电子 k 网格、声子 q 网格、插值网格、展宽、频率截断和温度采样。出现虚频时，先判断结构不稳定或数值未收敛，再决定是否需要非谐声子处理。Allen-Dynes 适合相应假设下的估计；多带或强各向异性问题应考虑显式求解能隙方程。

可使用 [EPW 官方教程](https://docs.epw-code.org/tutorials/tutorial_04/index.html) 的 Pb/MgB2 作为练习。教程为节省计算量所用的参数需要在生产计算中重新收敛；输入字段和安装步骤以对应版本的 [官方文档](https://docs.epw-code.org/Inputs/Inputs.html) 为准。

## 3. 电子关联路线

```text
实验约束/DFT → Wannier 低能模型 → 相互作用与双重计数约定
           → 正常态 Green 函数/响应 → 配对顶角 → 本征值与能隙
```

对模型记录填充数、化学势、晶格单位、能量单位与轨道顺序。若包括 SOC，需要保留合适的自旋/赝自旋矩阵结构。cRPA 参数依赖选定低能空间，不能直接照搬另一套轨道基的 U 和 J。

RPA 可作弱耦合起点。在磁性分母接近奇点时，检查近似是否仍有解释力；不能简单把发散附近很大的配对本征值当作可信的高 Tc 预测。固定温度下的配对本征值用于比较通道；若要给出转变尺度，需要扫描温度、控制截断和自能近似。

模型路线的主要文献入口是 [Scalapino 综述](https://doi.org/10.1103/RevModPhys.84.1383) 和 [掺杂 Mott 绝缘体综述](https://doi.org/10.1103/RevModPhys.78.17)。

## 4. 两种 λ 与两种温度尺度

`λ_ep` 表示电子-声子耦合常数；`λ_pair(T)` 表示线性化配对核本征值。两者定义不同，应在数据文件中使用不同列名。

`λ_pair(T)=1` 给出所用近似下的配对不稳定性。在二维、低载流子密度或强相位涨落体系，真实相位相干转变可能更低，需要计算超流刚度或 BKT 行为。普通平均场能隙方程没有自动包含这一修正。[二维吸引 Hubbard 与 BKT 理论](https://arxiv.org/abs/cond-mat/0311374)

## 5. 每次计算至少保存

- 输入与参数来源、代码/依赖版本、运行命令和随机种子（若使用）。
- 物理单位、归一化、晶胞/轨道基、网格、截断和收敛判据。
- 原始数值小表、画图脚本、图对应的运行编号。
- 解析极限或公开基准对比，以及至少一个关键数值参数的收敛检查。
- 未解决问题与失败日志。没有获得稳定结果也应如实记录。
