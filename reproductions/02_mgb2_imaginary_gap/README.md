## 比较规则，先定后算

必须有材料数据后才开展定量比较。以下是本项目**自定的预设学习阈值**，不是作者给出的精度。

1. 单位、10 K、μ*、谱/权重定义和带标签必须先一致；不一致时只能作差异分析。
2. 若有带/k 原始点集，按 DOS 权重在共同虚频点计算两组的均值与 10/90 分位范围。
3. 在共同虚频点、0–180 meV 展示区间报告逐带 RMSE、最大绝对差和低频差。
4. 数字表对照的暂定阈值：逐带 RMSE≤0.10 meV，最大差≤0.30 meV；阈值不能事后调宽。
5. 重算解的未混合能隙残差要求≤10^-7 meV，Z≤10^-8；这不是原图误差的替代品。
6. 若只有图像数字化，记录像素到坐标变换与误差；缺少点权重时不把像素密度当概率分布，不用其冒充原始均值/分位数。须另立可比较统计量与误差标准后再算。

如果只有材料带平均 Aᵢⱼ(Ω)，可先做**带平均近似复现**，但没有资格验收带内分布宽度。
