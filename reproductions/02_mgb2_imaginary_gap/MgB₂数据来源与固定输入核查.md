## 3. 固定输入与目标的差异

下表不评价谁更准确，只列可核对的差异；没有扫描、没有把历史输入改成新版本。
2013 栏依据 [arXiv:1211.3345v1](https://arxiv.org/abs/1211.3345v1) p6–7、p10 Fig. 6。
2026 栏来自 [EPW 官方教程的 MgB₂ FSR 部分](https://docs.epw-code.org/tutorials/tutorial_04/index.html)，
文档标注 QE 7.5 / EPW 6.0；网页可更新，非固定提交版本。

| 项目 | 2013 作者 v1 / 原图目标 | 2016 配套归档的实际输入 | 2026 教程 FSR |
|---|---|---|---|
| 交换关联 / 赝势路线 | LDA，norm-conserving | `.pz` 历史赝势文件名；未重新运行确认 | PBE，PseudoDojo ONCV |
| `ecutwfc` | 60 Ry | 40 Ry | NSCF 为 50 Ry |
| 初始 SCF k | 24³ | 12³ | 声子步骤 8³ |
| Wannier 粗 k / DFPT q | 6³ / 6³ | 6³ / 6³ | 6³ / 3³ |
| 细 k / q | 60³ / 30³ | 20³ / 20³ | 40³ / 20³ |
| `muc` | 0.16 | 0.16 | 0.10 |
| 温度 | Fig. 6 为 10 K | `nstemp=1`、`tempsmin=15`、`tempsmax=60` | 5–45 K，共 9 点 |
| 电子 EPC 展宽 | 100 meV | `degaussw=0.10 eV` | `0.05 eV` |
| 声子展宽 | 原文 p7 写 50 meV | `degaussq=0.5 meV` | `0.5 meV` |
| 虚频截止 | 10 × 最大声子频率 | `wscut=1.0 eV` | `0.5 eV` |
| `fsthick` | 此次未核定具体输入语义/值 | `0.4 eV` | `0.2 eV` |

**待澄清**：作者 v1 p7 的 50 meV 经页面图像核对，不只是文本抽取错误。
是否为原稿笔误、出版时修正、或不同计算设置，尚无证据；不能擅自改成 0.5。
出版 PDF 的 APS 接口本次返回未授权，未取得出版版，版本差异核对仍未完成。

同样，旧输入的 `nstemp=1` 与端点字段不能按现代 `temps` 语义猜测实际运行温度；
唯一可确认的是文本没有设置目标 10 K。以后须结合对应旧版本源码和实际日志。
旧 `etf_mem=.true.`、`parallel_k` 等关键词也不能直接套入现代输入。

## 4. 原图不是两条无权曲线

作者稿 p10 Fig. 6 图注说明：为清晰展示，从约 10⁷ 个计算点中取代表性的约 10⁵ 个点。
因此，图上的点密度既不自动等于全体态密度，也不自动等于 DOS 权重。
视觉上分成两组不等于已经取得 σ/π 带标签或点的配对关系。

本项目可先学习完整散点的单位与文件结构。
真正逐带比较还需要：同一次运行的 band/k 标签、权重、温度/μ*、电子窗口、频率与版本信息。
仅有两列 ω/Δ 的绘图投影，也不能恢复被删掉的状态信息。

## 6. 可离线重做的核查

取得该公开小归档及记录 API JSON 后，在本项目目录运行：

```powershell
python -B archive_audit.py G:\codex\mgb2_data_source_cache\Ponce-CPC-2016.tar G:\codex\mgb2_data_source_cache\record.json
python -B -m unittest -v test_gap_io test_archive_audit
```

第一步核对固定 SHA256 和 MD5，仅按白名单保存四个输入。
清点与复制共用一次读取的不可变归档字节，避免校验后又打开另一份文件。
不执行上游代码，不解包任意路径；拒绝链接、路径穿越、大小超限和大小写重复路径。
所有输出预检解析后的目录归属与 Windows 重解析点；目录链接不允许绕过项目边界。
普通输出文件的多重硬链接也拒绝；同目录临时文件加原子替换，避免原位改写共享文件。
API 固定快照 SHA256 也核对，并检查版本、归档条目、署名与许可。
此核查器只支持本次固定快照。重新下载的 API 响应即使元数据未变，也可能因为动态字段改变摘要；
应先复核并明确升级来源记录，不以关闭哈希检查绕过错误。
它会重建清单；已被修改的输入拒绝覆盖。此工具没有下载、SSH 或作业提交能力。
日常学习不需要归档缓存，直接看已入库副本和执行 Notebook 即可。
