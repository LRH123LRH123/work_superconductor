# 文献复现指南

[返回首页](../README.md) · [复现记录模板](../templates/复现记录模板.md)

当前没有已完成复现案例。下面定义后续案例的组织方式和验收要求。

## 选择一个可核验的目标

优先选择能明确指出“论文 Fig. X 的某条曲线”或“Table Y 的某个数值”的任务。先记录 DOI、论文版本、目标图表、Hamiltonian、全部可得参数及缺失项。若缺失参数需要自行假设，说明假设对结果的影响。

推荐首个项目为 BCS/BdG 解析基准或 EPW 官方超导教程。它们用于建立数值能力，不能自动等同于原始论文复现。

## 目录约定

每个项目使用独立英文短目录名，例如 `年份-作者-主题/`。以下目录仅为模板，尚未建立：

```text
项目目录/
  README.md          按复现记录模板填写：目标、状态、环境、命令、结论
  inputs/            参数和计算输入
  scripts/           计算与作图脚本
  environment/       锁定版本的环境文件
  results/           小型数据表与关键结果
  figures/           自己生成的比较图
```

大型数据可放外部存储，README 写明获取位置、SHA256、大小和生成步骤。敏感凭证和机器私有路径不写入公开输入。

## 从最小算例到复现结论

1. 检查单位、晶格常数、轨道顺序、Fourier 变换与自旋/DOS 归一化。
2. 用解析极限或小规模算例验证计算流程。
3. 逐步增加网格、尺寸、频率截断或键维度，并保存收敛表。
4. 使用相同物理条件与原文对照；保存绝对/相对误差，说明原文数据是否经过数字化。
5. 从干净环境按记录命令重跑关键结果，再更新状态。

## 状态与完成标准

| 状态 | 含义 |
|---|---|
| 计划中 | 已选定论文或基准，尚未运行 |
| 进行中 | 正在构建与计算，结果未完成核验 |
| 部分复现 | 部分目标达到预先声明的容差，剩余差异有记录 |
| 已复现 | 声明的目标均达标，环境、命令、输入、收敛与误差可追溯 |
| 暂时阻塞 | 明确记录缺少的数据、计算资源或理论信息 |

容差由目标精度、原文误差和数据读取精度决定，应在比较前设定。不能只凭“曲线形状相似”宣布定量复现，也不要求每个练习都完成整篇论文的所有结果。
